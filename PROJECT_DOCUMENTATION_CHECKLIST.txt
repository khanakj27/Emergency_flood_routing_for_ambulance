Component Breakdown:
- Feature Groups:
  1. Ambulance Features (11): GPS lat, GPS lon, vehicle type, speed, heading, priority level, equipment tier, fuel level, crew status, dispatch timestamp, target operational zone.
  2. Road-Segment Features (19): Segment ID, length, surface type, lane count, speed limit, current traffic speed, historical baseline speed, elevation profile, drainage status, flood severity, flood probability, prediction confidence, closure flag, signal count, turn penalty, bridge flag, underpass flag, width, surface condition.
  3. Weather Features (10): Precipitation rate (mm/h), 1h accumulated rain, 3h forecast rain, temperature, humidity, visibility, wind speed, thunderstorm flag, weather warning severity, sensor data timestamp.
  4. Flood-Related Features (10): Water depth estimate (cm), surface inundation ratio, flood severity score (0-1), detection model probability, prediction confidence index, dynamic growth rate, distance to nearest lake/drain (Kaluve), historical flood frequency, water accumulation speed, flood risk tier (Low/Mod/High/Blocked).
  5. Hospital Features (13): Hospital ID, latitude, longitude, emergency tier (Level 1/2/3), 24/7 status, ICU bed availability, oxygen availability, specialized trauma unit flag, ambulance entry accessibility, current queue delay, baseline rating, operational status, contact status.
  6. Route-Level Features (12): Total distance (km), estimated travel time (min), total flood exposure ratio (%), max flood severity along path, traffic delay component, ambulance suitability penalty, turn complexity index, safety score, route confidence score, green corridor activation feasibility, recalculation count, route strategy type.

Color & Thickness Conventions:
- Nodes (Vertices): Intersections (N1, N2...) and Facilities (Ambulance Start A, Target Hospitals H1, H2).
- Green Edges (Thin/Medium): Clear, normal travel time, risk weight w = 1.0.
- Yellow / Amber Edges (Medium): Moderate traffic or low flood risk, weight penalty w = 1.5 - 3.0.
- Red Edges (Thick / Dashed cross): High flood severity (>= 0.80) or confirmed closure, weight w = INFINITY (Blocked).
- Dynamic Attributes on Edges:
  * Edge (Richmond Cir -> MG Road): Severity = 0.85, Conf = 0.90 -> STATUS: BLOCKED.
  * Edge (Richmond Cir -> Hosur Rd): Severity = 0.15, Conf = 0.80 -> STATUS: CLEAR (Reroute Selected).

FIGURE 4: Flood-Detection to Road-Segment Risk Pipeline
-------------------------------------------------------
Type: Pipeline / Flow Diagram
Placement: Section III.C.1 (Flood-Detection Module)
Caption: "Fig. 4. Pipeline converting semantic-segmentation predictions into road-segment flood risk scores."

Pipeline Sequence (Left to Right):
[Aerial / Drone Image] ──> [Pre-processing & Normalization (512x512)]
                                    │
                                    ▼
                 [Semantic Segmentation Model (DeepLabV3+ / U-Net)]
                                    │
                                    ▼
                 [Pixel-wise Binary / Multi-Class Flood Mask]
                                    │
                                    ▼
                 [Spatial Overlap Aggregation with OSM Road Geometry]
                                    │
                                    ▼
                 [Calculate Segment Metrics: Severity (S), Prob (P), Conf (C)]
                                    │
                                    ▼
                 [Rule-based Penalty Assignment to Graph Edge Weights]
                 - If S>=0.80 & C>=0.75 -> Infinite Weight (Blocked)
                 - If S>=0.50 -> 3.0x Cost Weight (High Risk)
                 - If S>=0.20 -> 1.5x Cost Weight (Moderate Risk)
